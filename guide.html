Your First Quantum Program

NovaLang syntax is beginner-friendly. Try this Bell state:

q0 = qubit()
q1 = qubit()
h(q0)
cx(q0, q1)
measure(q0)
measure(q1)
print("Bell state created!")

Click ▶ Run Code to execute.

⚛️ Quantum Gates Reference

🎯 Single-Qubit Gates

  • h(q) — Hadamard (creates superposition)
  • x(q) — Pauli-X (NOT gate)
  • y(q) — Pauli-Y (phase + NOT)
  • z(q) — Pauli-Z (phase flip)
  • rx(q, θ) — Rotation around X axis
  • ry(q, θ) — Rotation around Y axis
  • rz(q, θ) — Rotation around Z axis

🔗 Two-Qubit Gates

  • cx(q1, q2) — CNOT (controlled-X)
  • cz(q1, q2) — Controlled-Z
  • swap(q1, q2) — Swap qubits
