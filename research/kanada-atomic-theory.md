# 🧪 Kanada Rishi — પ્રથમ અણુ સિદ્ધાંતકર્તા

## મૂળ સમજૂતાં

**Kanada Rishi** (લગભગ 3rd century BCE) ના **વૈષેષિકતા સૂત્ર**માં પ્રથમ વખત અણુ સિદ્ધાંત વર્ણવાયેલ છે:

> "અણુઃ પરમાણુઃ ચ દ્વયમ் અણુઃ પરમાણુઃ"  
> - વૈષેષિકતા સૂત્ર ૧.૧.૧૧

## મહત્વ

- **અણુ (Anu)** = અણું (atom)
- **પરમાણુઃ (Paramāṇuḥ)** = ઉપાણુ (sub-atomic)
- આ જ્ઞાન **ઈશર્જન** અને **આટલંગ** પછી આવે છે!

## આધુનિક ક્વાણ્ટમ મેકેનિક્સમાં અસર

Kanadaના સિદ્ધાંતો આજેના ક્વાણ્ટમ કમ્પ્યુટિંગ પર પ્રતીકાર કરે છે:

```
| વસ્તુ | ક્વાણ્ટમ દૃશ્ય |
|-------|------------|
| પરમાણુઃ | ક્વાણ્ટમ ડ્રાયડનો સર્વત્રપણ હોવું |
| અણુઃ | ક્વાણ્ટમ સ્થિતિનું નિર્ધાન |
```

## નિષ્કર્ષ

Kanada Rishiનું જ્ઞાન **વૈદિક વિજ્ઞાન** અને **આધુનિક ક્વાણ્ટમ તત્વવાદ** વચ્ચે જોડાણ છે!
